## Las 10 formas

10. Vender sistemas, no prompts sueltos
9. Contenido mensual para negocios locales
8. Chatbots que contestan, califican y agendan
7. Imagen y video como servicio
6. Mini curso, membresía o boletín
5. Productos digitales que se venden solos
4. Freelance de automatización
3. Un micro software con pago mensual
2. Agencia para 3 o 4 empresas
1. Tu propio producto y tu propia audiencia
